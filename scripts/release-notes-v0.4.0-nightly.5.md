### ✨ Novidades

- Novas opções de privacidade para autorizar separadamente o envio de diagnósticos de conexão e de cores do compartilhamento de tela.
- Teste de fidelidade sob demanda com padrões de cores gerados pelo NEXUS, sem capturar conteúdo pessoal.
- Comparação sintética opcional entre participantes autorizados, mantendo a tela compartilhada durante o teste.

### 🚀 Melhorias

- Os diagnósticos autorizados podem ser enviados automaticamente para análise privada, facilitando a comparação entre participantes quando uma tela conecta para algumas pessoas e falha para outras.
- Indicação visível da coleta, opção para desativá-la imediatamente e informação sobre o estado do último envio.
